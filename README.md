# python-background-remover

# 🖼️ Python Background Remover

A fast and easy-to-use Python application that removes the background from images using Artificial Intelligence.

## ✨ Features

- 🎯 AI-powered background removal
- 🖼️ Supports PNG, JPG, and JPEG images
- ⚡ Fast image processing
- 💾 Saves images with transparent backgrounds
- 🖥️ Simple and beginner-friendly
- 📂 Process one image at a time
- 🔍 High-quality output

---

## 📸 Example

### Input
An image with a normal background.

### Output
The same image with the background removed and a transparent PNG.

---

## 🛠️ Technologies Used

- Python 3
- rembg
- Pillow (PIL)
- NumPy

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/AMI-labs/python-background-remover.git
```

Go into the project folder:

```bash
cd python-background-remover
```

Install the required packages:

```bash
pip install -r requirements.txt
```

---

## 🚀 Usage

Run the application:

```bash
python main.py
```

Follow the instructions to:

1. Select an image.
2. Remove the background.
3. Save the new transparent image.
